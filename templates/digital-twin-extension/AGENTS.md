Read https://github.com/christian-ri/penn-state-dt-extensions/blob/main/docs/getting-started.md and the SDK declarations installed in node_modules. Use only documented SDK APIs. Do not import private Core modules. Run npm ci, npm run build, npm test, npm run validate. Use npm run dev for the local sandbox. Synthetic fixtures do not prove Core integration. Keep extension.manifest.json as the only manifest source. Never add secrets, production credentials, restricted data, or self-hosted workflows. Submit a source tag, artifact checksum and data-handling note to a Core maintainer.
